# Drainage Report Standard v0.4.0 - change spec

Status: SPEC ONLY. The package on EKOS is still v0.3.0 until every item below is implemented and passes the
regression suite (section R) in Phase 5. Skill `drainage-report-standard` v0.4.0 describes how to work with the
v0.3 package today and which library helpers stand in for these changes until they ship.

Package (EKOS): `D:\LocalAI_Test\Drainage_Report_Standard_v0.3_TRANSFER\Drainage_Report_Standard_v0.3_TRANSFER`
`<STANDARD>` below = `<package>\standard\30_Standard_v0.3` (v0.3) or `<package>\standard\30_Standard_v0.4` (new release folder).

Locating code: the v0.3 source was not available when this spec was written, so functions are named by what they
do and anchored to the text they print (e.g. the `_ASSEMBLY_REPORT.md` line "OK version gate"). Phase 5 records the
actual function names in the implementation log beside each CS id.

Sources: clusters QC-C04, QC-C05, RPT-C01, RPT-C06, RPT-C10, HYD-C26, HYD-C27, HJR-C10, HJR-C19, DSO-C14, DSO-C31,
EXH-C13; decisions D16, D44, D45, D47, D48, D50, D51, D52, D56. Items marked "(default, to confirm)" carry a
decision JCO accepted as a default without confirming the fact.

## CS-11 Table content rules (RPT-C06)
- `tables.json`: per-column `precision` and `thousands` keys; defaults: elevations 2 decimals, no separator;
  discharges whole cfs; one precision per column. The table writer formats from these keys, never from cell text.
- Per-block `drop_if_constant: true`: constant columns are dropped and stated in the source note; landscape only if
  more than 10 columns remain.

  Table n" sentence kept (v0.2 behaviour).
- Page breaks only before main sections and appendices; 11x17 figures grouped at the end of their main section;
  appendix tables fitted to one page where possible, header repeated when a table breaks.
- 8.0 References numbered 1), 2), ...; real sources only.
- Directions abbreviated with a period (S.) or written out; one convention per report (style check in
  postprocess_docx.py).
- Test: regression tables: elevations show 2 decimals, no "2,707.50"; a block with a constant column prints without it
  and with the note.
