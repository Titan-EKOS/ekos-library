# EKOS Library

Shared skills, agents and QC rules for drainage, H&H and civil work at Psomas. One master copy of each; every AI reads from it and writes lessons back to 07_Inbox. Owner: JCO.

## Layout
| Folder | Holds |
|---|---|
| 00_Inventory | project_index.csv; `_local\` (gitignored) client terms and path aliases |
| 01_Cards | harvested cards by project; card template |
| 02_Clusters | grouped cards, conflicts.md, build ranking |
| 03_Skills | skill masters (`<name>\SKILL.md` + resources) |
| 04_Agents | agent masters (`<name>\AGENT.md`) |
| 05_QC_Rules | rules.md, each rule tied to its redline |
| 06_Regression | test-run scores per version |
| 07_Inbox | append-only cards and lessons from every AI |
| 08_Platform_Builds | build.py, generated `out\` (never hand-edit), CONNECT_*.md |
| 09_Server | MCP server, CLI, tests |

## Change rules
- Masters change only after JCO approves: version bump, change log entry, `build.py`, commit.
- Generated files in `08_Platform_Builds\out` come only from `build.py`; the pre-commit hook rejects drift.
- Cards and lessons: lessons and file paths only, job numbers instead of client names. The data guard rejects client data.
- Naming: `JCO_YYYYMMDD_<topic>` for cards, inbox files, regression runs and logs. Skill and agent folders use kebab-case slugs (required by Claude skills).

## Connecting each AI
See `08_Platform_Builds\CONNECT_Claude.md`, `CONNECT_Codex.md`, `CONNECT_ChatGPT.md`, `CONNECT_Gemini.md`, `CONNECT_Local.md`.
