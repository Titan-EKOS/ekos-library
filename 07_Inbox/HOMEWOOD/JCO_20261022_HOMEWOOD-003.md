type: skill
function: hydraulics-model-run
trigger: Storage, peak control or HGL must be shown with a hydrograph model while
  the agency peak-flow method is Small Watershed (or other rational-type method).
steps:
- Compute target peaks per area for 10/25/100-yr with the county method.
- Set constant-rate infiltration (Horton f0 = fc = Table 5-3 rate), no depression
  storage.
- For each storm bisect subcatchment width in log space (about 26 iterations) on a
  runoff-only model until modeled peak matches target.
- Use the geometric mean of the storm-specific widths as the single width; report
  fit (target within 10%; achieved +/-4% West, +/-8% East).
- Carry calibrated widths into all routed scenarios and plot a calibration figure.
gotchas:
- Switching SSA hydrology between TR-55 and TR-20 never matched county peaks (50-yr
  0.13 vs 0.90 cfs); calibration of width is what closes the gap.
- Calibrate pre-condition catchment separately with its own target.
