trigger: Owner wants a complete drainage plan set for grant applications and the option

steps:
- Walk the roll plot from the outfall upstream and break segments where a governing
  constraint changes.
- Score each segment for real property, utilities, irrigation district relocation
  (underground or not), access during and after construction, unresolved design items
  and need for community input.
- Phase by work type as well as by station: drainage channel, culverts and base path
    first; park amenities later.
- Assume one comprehensive plan set (CMAR can build by station range); separate bid
  packages are additional services.
- Stop design short of jurisdictional waters at the river tie-in unless a 404 delineation
  is in hand.
- Allocate the overall cost estimate to each phase so the owner can match CIP funding.
- Hold the phasing workshop early in final design with traffic, planning and the owner
  present.
gotchas:
- An outfall-only phase spends money without function until the channel upstream is
  built; check each phase delivers benefit alone.
- Irrigation district asked for new easements matching existing ones wherever facilities
  are relocated; this came after plans were drawn.
