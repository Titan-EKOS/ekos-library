  depth differences treat dry as 0 ft.

  plan, scenario, variable, units, sign, source raster).
- Export the terrain used for depth as its own raster per scenario so the receiver
  can recompute depth.
gotchas:
- Without the plan number in the dictionary the receiver cannot tie a raster to a
  run when plan titles and file tokens differ (TDAFW vs Mitigate_FW).
